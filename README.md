Portfolio Website – Built with React.js
This repository contains the source code for my personal portfolio website, built entirely using React.js.
The website showcases my projects, skills, experience, and achievements in a clean, responsive, and modern UI.

Project Overview
The portfolio website is designed to create a strong professional online presence.
It highlights my journey as a Computer Science & Engineering student, my work in Web Development and Machine Learning, and provides easy access to my projects and contact details.

 Key Features:
 Built completely with React.js
 Fully responsive design
 Clean and modern UI
 Fast loading and optimized performance
 Projects showcase with details
 About, Skills & Contact sections



Tech Stack
Frontend: React.js
Styling: CSS
Language: JavaScript, HTML
Build Tool: Node.js & npm
